# 三國・陀螺爭霸 / SPIN FOR GLORY

18 位武將、專屬陀螺外觀與半即時技能對戰。支援單人挑戰電腦、同機雙人及遠端雙人房間。

**遊戲網址（Pages 部署完成後）：https://weilitien.github.io/beyblade/**

## 遠端對戰

房主選「遠端雙人 · 邀請朋友」→ 建立房間 → 複製邀請連結。朋友開啟連結並按加入房間。兩人各自選將，都用空白鍵發射、1–8 通用技、Q 專屬技、P 暫停。

雙方鎖定發射時機後開戰；房主計算戰鬥並同步給訪客。房主需保持頁面開啟，部分受限網路需要額外 TURN 中繼。

詳見 [連線、測試與部署說明](ONLINE.md)。

## 本機啟動

```sh
python3 -m http.server 8082
```

開啟 http://localhost:8082/。`tests.html` 可執行引擎測試；CI 以 `node scripts/check.cjs` 檢查 74 項規則及 JavaScript 語法。

## 原型範圍

陀螺自動移動碰撞，玩家選擇技能時機。馬超、龐德、夏侯惇、甘寧、孫策採使用者設計文件數值，其餘角色與未指定參數為暫定平衡值。這是 Canvas 投影幾何的瀏覽器原型，非官方 Beyblade 遊戲。

24 秒宣傳片位於 [promo/](promo/)。PeerJS 1.5.5 的授權位於 [vendor/peerjs.LICENSE](vendor/peerjs.LICENSE)。

## 音效

音效預設開啟（音量 70%），首次點擊或按鍵後自動啟用。可聽到加強低頻的金屬撞擊，以及 8 招通用技、18 招武將專屬音型；右上可靜音或調整音量。遠端音效事件同步且不重播。詳見 [音效說明](AUDIO.md)。

## 閱讀與維護程式

程式已依區塊展開排版；Python 共用瀏覽器工具與 JavaScript 測試情境分開。請從 [程式導讀](CODE_GUIDE.md) 找要修改的功能。

## 戰鬥畫面

主頁先按「進入戰鬥畫面」，此時尚未蓄力；進入後再按「蓄力發射」，遠端模式則按準備並等待雙方就緒。桌機技能在戰場旁，手機直向在下方，全部 9 招保留在視窗內。遠端只顯示自己的技能；同機雙人窄螢幕可切換 P1／P2 技能面板。按「招式說明」查看完整效果，按「返回頁面」或 Escape 先暫停再離開；重新選將則回到設定頁。音量與靜音仍可直接操作。

`python3 scripts/layout-smoke.py` 驗證八種視窗尺寸（含 320×568 與 568×320）、戰場高度、單人與同機雙人的觸控發射／九個技能／暫停、離開返回與面板切換。手機控制項至少 44px 高；矮螢幕技能區可獨立捲動，保留戰場空間。測試使用 Chrome 裝置模擬，仍需以實機確認 Safari 與瀏海安全區。

## 新增黃忠

金銅弓翼、箭鏃刃口與弓箭徽章。專屬技「百步穿楊」消耗 45 魔法、冷卻 12 秒：瞄準方向固定，蓄力 1 秒後射出直線衝擊，命中造成 2.4 倍傷害並忽略 20% 防禦；可走位躲避，受擊中斷。黃忠數值屬暫定平衡值。

## 新增魏、吳武將（暫定平衡值）

- 典韋／魏：攻擊86、防禦72、生命1150、速度45、穩定85。「古之惡來」消耗40魔法、冷卻12秒，8秒內碰撞命中每層增加15%碰撞傷害，最高4層；距離超過2或到期歸零，閃避不增加層數。
- 陸遜／吳：攻擊68、防禦46、生命950、速度82、穩定52。「火燒連營」消耗45魔法、冷卻12秒，6秒內移動至少0.35且距離上次留痕至少0.3秒才留下火痕。火痕半徑0.55、保留2秒，每0.5秒造成0.25倍傷害；重疊不加傷、遵守減傷，不可閃避且不觸發反震，與既有火區一致。

## 戰後操作

勝負原因下方提供「再戰一場」與「重新選將」。再戰保留目前武將並開始蓄力；遠端需雙方按再戰才開始，先準備的一方會看到等待提示。重新選將返回設定頁，遠端由房主操作。矮螢幕的結算卡片可捲動。
