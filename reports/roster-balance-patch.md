# 2026-10 第一輪全角色平衡

基準提交：52058be。平衡版本：2026-10-roster-1。連線版本更新為spin-arena-remote-8，避免新舊數值玩家混用。

## 目標與結果

18位角色全配對檢查，調整17位，黃忠保持原值。保留角色技能效果、倍率、冷卻、發射、移動與傷害公式；調整基礎攻防／生命／穩定度、馬超與貂蟬速度，以及曹操、周瑜、貂蟬、陸遜的專屬技消耗。所有原始數值保留在WarData.originalStats；平衡值集中於WarData.balanceAdjustments，UI明示「平衡值」。

初始目標是降低明顯極端，不追求每一種策略或對位都50%。這一輪不代表已達競技平衡，仍需玩家實測。

## 驗證方法

全18角色的153組非鏡像配對，兩套策略（專屬優先混用通用技／僅使用專屬技），每組4個固定seed，交換P1/P2，共2,448場。調參組seed1–4；最終保留組seed5–8，未依保留組結果繼續調數值。改前、改後兩組共9,792場。相同0.8發射品質、1/120秒模擬，每0.5秒決策；平手算半分，故下表為得分率而非純勝率。兩策略等權，每位角色每組272場。
固定腳本未模擬真人誘敵、預判或依角色最佳化選招。seed主要改變選招順序與機率技，同策略部分樣本可重複，不視為獨立玩家樣本。保留組仍沿用相同策略家族，不等同新玩家族群的獨立驗證。

## 調整理由與尚存差異

- 典韋、夏侯惇、趙雲、張飛、龐德原本同時擁有偏強的近戰輸出／承傷能力，降低部分攻防與穩定，不刪除連擊、反擊、坦克及絕境特色。
- 貂蟬原本基礎能力過低，反噬不足以彌補；提高基礎能力並把消耗40降至30。諸葛亮補足基礎輸出與生存，減少完全仰賴低機率擊倒；擊倒率與消耗全部魔法機制不變。
- 呂布補足過低的穩定與防禦；馬超、甘寧改善容易被擊退／爆裂的弱點。馬超速度92降至84，仍保有高速突進技能，降低過度追擊風險。
- 陸遜補強輸出與生存、專屬消耗45降至40；火痕範圍、時間、傷害與重疊限制不變。
- 曹操、周瑜降低專屬消耗5點，保留封招與火區控制角色特色。黃忠沒有足夠證據需要直接更改，保留原值。
- 保留組仍有明顯策略差：張飛混合策略75.7%、僅專屬28.7%；趙雲混合19.9%、僅專屬52.9%。這些是之後實玩與策略測試重點，不能將整體得分範圍誤讀成各情境皆公平。
- 極端一對一剋制仍可能存在；原始JSON提供逐配對結果，未以強制勝率修正、隱藏補正或動態傷害操控結果。

## 重跑

在遊戲根目錄執行；原始資料模式可重建修改前結果，不需切Git版本：

```sh
node scripts/roster-balance.cjs --original --output=/private/tmp/roster-before.json
node scripts/roster-balance.cjs --output=/private/tmp/roster-after.json
node scripts/roster-balance.cjs --original --offset=4 --output=/private/tmp/roster-holdout-before.json
node scripts/roster-balance.cjs --offset=4 --output=/private/tmp/roster-holdout-after.json
node scripts/check.cjs
python3 scripts/signature-smoke.py
python3 scripts/remote-smoke.py
```

瀏覽器測試需先啟動localhost:8082，並使用macOS Chrome。遠端測試會短暫使用公開房間1。原始結果為本目錄四份roster-*.json，舊的balance-*.json保留為歷史量測。
